# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment or discrimination of
any kind. Maintainers may remove, edit, or reject contributions and ban
contributors for behavior that violates this.

Report problems by opening a private security advisory on GitHub or emailing
the maintainers listed in the repository.
